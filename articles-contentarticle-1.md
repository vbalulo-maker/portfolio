# Как построить архитектуру микросервисов

Микросервисная архитектура стала стандартом для крупных распределённых систем.

## Ключевые принципы

1. **Децентрализация данных** — каждый сервис владеет своей БД.
2. **API-шлюз** — единая точка входа для клиентов.
3. **Событийное взаимодействие** — используйте брокеры сообщений (Kafka, RabbitMQ).

## Практический пример

```yaml
services:
  auth:
    port: 8081
  orders:
